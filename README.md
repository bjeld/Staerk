# STÆRK

iPhone-app til vaner, styrketræning og krop. Alt gemmes lokalt på telefonen. Apple Health er valgfrit.

Hjemmeskærmsnavn: **Styrke**.

Åbn `ios/Staerk.xcodeproj` i Xcode 15+ og kør på iPhone (iOS 17+). Vaner, sæt/reps-træning eller cirkel/LOOP, krop og Apple Health. Arkitektur, signing, HealthKit, migration og tests: [ios/README.md](ios/README.md).
